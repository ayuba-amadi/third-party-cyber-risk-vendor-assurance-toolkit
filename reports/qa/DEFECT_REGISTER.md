# Browser QA defect register

Create one entry per distinct defect using the [defect report template](../../03-testing-and-quality-assurance/DEFECT_REPORT_TEMPLATE.md). Link every failed execution to its defect ID, including repeat observations of an existing defect. Chat can alert the team. This register is the required record.

Keep the original observation and append each browser retest with the tested commit, result and evidence. For Medium defects accepted for release, record the reviewer and rationale. [Execution log](TEST_EXECUTION_LOG.csv) · [Evidence storage](evidence/)
