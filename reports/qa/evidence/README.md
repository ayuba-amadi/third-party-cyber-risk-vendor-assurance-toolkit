# Browser QA evidence

Save evidence under `reports/qa/evidence/<tested-commit>/<WAT-date>/<tester-and-attempt>/`. Use `QA-<TEST-ID>-<short-description>.png` for screenshots. Examples include `QA-UI-001-dashboard-loaded.png`, `QA-UI-004-duplicate-vendor-rejected.png` and `QA-UI-010-overdue-action-visible.png`. Use the same naming pattern with the original extension for downloads.

Add repository-relative paths to the [execution log](../TEST_EXECUTION_LOG.csv) and, when applicable, the [defect register](../DEFECT_REGISTER.md). Save a separate file per observed state and retain the original evidence when adding retests. A PASS requires a screenshot or download showing the expected browser result. Store any supplementary terminal evidence separately within the run.

Use fictional data only. Exclude real supplier evidence, credentials, personal data and confidential screenshots or downloads.
