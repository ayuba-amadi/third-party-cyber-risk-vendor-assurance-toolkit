# Operating model

| Role | Responsibility | Record |
|---|---|---|
| Business owner | Describe service dependency and review material changes | Vendor, service link, change event |
| GRC analyst | Validate inputs and prepare the assessment | Assessment, response, calculation |
| Data protection officer or evidence reviewer | Review data handling and document verification | Evidence metadata, audit entry |
| Authorised approver | Review the evidence and record a justified outcome | Decision, conditions, expiry and review date |
| Remediation owner | Implement corrective work and submit closure evidence | Corrective action and status |
| Management | Review concentrations, overdue items and open conditions | Dated management report |

Work with fictional data. Export session records before resetting. Use stable IDs, retain earlier assessment versions, and link changes to the applicable version. On material change, reassess and obtain a new human decision. Close actions only after the responsible reviewer has verified completion. In this demo, the user's role entry records the claimed role. Any real authority and retention requirements would need separate controls.
